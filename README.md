## 📌 SOBRE O PROJETO  
  
O **OptimizerX** é uma ferramenta em Batch que automatiza ajustes essenciais do Windows de forma rápida, direta e transparente.  
  
Projetado para quem quer **melhorar o sistema sem perder tempo** com configurações manuais.  
  
---  
  
## 🚀 DIFERENCIAL  
  
- ⚡ Leve e rápido (sem instalação)  
- 🔍 Código aberto e auditável  
- 🧠 Sem processos ocultos  
- 📦 Sem coleta de dados  
- 🎯 Execução direta (1 arquivo .bat)  
- 🖥️ Interface interativa no terminal  
  
---  
  
## ✨ FUNCIONALIDADES  
  
- ⚡ Ajustes de performance (energia + Game Mode)  
- 🌐 Reset completo de rede e DNS  
- 🎮 Ajustes de responsividade (input)  
- 🧹 Limpeza avançada de arquivos temporários  
- 📦 Remoção de bloatware do Windows  
- 🖥️ Menu interativo no terminal  
  
---  
  
## 🧠 O QUE ESTE PROJETO NÃO FAZ  
  
- NÃO garante aumento de FPS   
- NÃO reduz ping real em servidores   
- NÃO substitui hardware melhor   
  
👉 Atua apenas em otimizações locais do sistema.  
  
---  
  
## ⚠️ AVISO IMPORTANTE  
  
Este script realiza alterações no sistema operacional.  
  
- Pode modificar configurações do Windows   
- Pode remover aplicativos pré-instalados   
- Pode alterar comportamento da rede   
  
👉 RECOMENDADO:  
  
- Criar um ponto de restauração antes de usar   
- Executar apenas como administrador   
  
Use com responsabilidade.

## ⚙️ DETALHES TÉCNICOS

### 🔹 Performance

-   Criação e ativação de plano de energia otimizado
-   Ativação do modo jogo

----------

### 🔹 Rede

-   Flush DNS
-   Reset de IP
-   Reset de Winsock

👉 Pode corrigir problemas de conexão (não reduz latência externa)

----------

### 🔹 Input Lag

-   Ajustes via `bcdedit`

⚠️ Pode alterar comportamento do sistema

----------

### 🔹 Limpeza

-   Remoção de arquivos temporários
-   Limpeza de cache
-   Desativação de hibernação

----------

### 🔹 Bloatware

-   Remoção de aplicativos pré-instalados
-   Execução individual ou em massa

----------
